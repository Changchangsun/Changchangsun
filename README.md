# Changchang Sun — Academic Homepage

🔗 **Live site: https://changchangsun.github.io/Changchangsun/**

Personal academic homepage of Changchang Sun (Ph.D. student, CS @ University of
Illinois Chicago), hosted with GitHub Pages.

## Structure

| Path | Content |
|---|---|
| `index.html` | The homepage (single page) |
| `index_files/` | Stylesheet (`jemdoc.css`) and assets |
| `files/` | CV PDF, profile photo, logos, favicon |
| `files/pubs/` | Teaser / pipeline figures for publications |
| `bibs/` | BibTeX files linked from each publication |

## Updating

- **New publication**: add an entry in the Publications section of
  `index.html`, drop its figure into `files/pubs/`, its BibTeX into `bibs/`,
  and add a line to News.
- **CV**: replace `files/Changchang_Sun_s_Academic_CV.pdf` (keep the filename
  so the links stay valid).
- Changes go live a minute or two after pushing to `main`.
